# 2D-среда гонок для RL Fun

**Дата:** 2026-10-08  
**Статус:** дизайн согласован с пользователем

## 1. Зачем нужен этап

Нужна наглядная среда для экспериментов: замкнутая 2D-трасса, на которой едет машинка с лучевыми сенсорами, как в роликах про обучение ИИ вождению. Этап добавляет только среду, интерактивную отрисовку и ручное управление. Модели, обучение и нейросети остаются следующими этапами.

Среда остаётся обычной Gymnasium-средой: runtime, `random`-алгоритм, `train.py` и `evaluate.py` работают с ней без изменений.

Учебные пояснения, README и подсказки CLI пишутся на русском. Python-идентификаторы остаются на английском.

## 2. Что входит

- Трасса из осевой линии и ширины, загрузка из JSON, набор готовых трасс.
- Сменная модель динамики с кинематической «велосипедной» моделью по умолчанию.
- Лучевые сенсоры расстояния до границ трассы.
- Среда `RLFun/Racing-v0`.
- Отрисовка на pygame (`human` и `rgb_array`).
- `scripts/play.py` для ручного вождения.
- Место под будущую панель нейросети в рендерере.
- Русский раздел в README, зависимость `pygame` в `pyproject.toml`.

## 3. Что не входит

Обучение и модели, PyTorch, панель нейросети с живыми весами, редактор трасс, штрафы и замедление на траве, динамика с боковым сносом, режим воспроизведения обученных моделей.

## 4. Состав (`src/rl_fun/racing/`)

- `track.py` — `Track`: осевая линия (замкнутый список точек), ширина, границы, старт, прогресс вдоль осевой линии, проверка «внутри трассы». Загрузка из JSON: `{"name", "width", "centerline": [[x, y], ...]}`. Готовые файлы лежат в `src/rl_fun/racing/tracks/`.
- `dynamics.py` — протокол `VehicleDynamics.step(state, steer, throttle, dt) -> state` и `KinematicBicycle`. Состояние: позиция, курс, продольная скорость, боковая скорость, угловая скорость. Модель со сносом позже добавляется отдельным классом и выбирается параметром без изменения среды.
- `sensors.py` — лучи под заданными углами, расстояние до границы трассы, нормированное на дальность.
- `env.py` — `RacingEnv(gym.Env)`, регистрация в `LOCAL_ENVIRONMENTS` как `RLFun/Racing-v0`.
- `render.py` — pygame: трасса, поребрики, стартовая линия, машинка, лучи, информационная панель. Окно делится на область игры и боковую область, куда позже подключается необязательная панель нейросети.

## 5. Контракт среды

- **Действие:** `Box([-1, -1], [1, 1])`, руль и газ/тормоз. Отрицательное значение тормозит до нулевой скорости, заднего хода нет.
- **Наблюдение:** нормированный вектор `float32`: расстояния лучей, продольная скорость, боковая скорость (при кинематике всегда 0), угловая скорость.
- **Награда за шаг:** прирост прогресса вдоль осевой линии в долях круга.
- **Конец эпизода:** `terminated` при столкновении с границей и при завершении круга; `truncated` по лимиту шагов. Выезд на траву не штрафуется отдельно: граница трассы является стеной.
- **`info`:** прогресс, номер круга, флаг столкновения.
- **Параметры (`environment.kwargs`):** трасса, динамика, число и дальность лучей, `dt`, лимит шагов. `render_mode` передаётся отдельно, как принято в проекте.

## 6. Интерактивность

- `render_mode="human"` открывает окно, `"rgb_array"` возвращает кадры.
- `scripts/play.py`: стрелки/WASD, `R` — перезапуск, `Esc` — выход, трасса выбирается аргументом.
- Для тестов используется `SDL_VIDEODRIVER=dummy`.

## 7. Ошибки

Некорректная трасса (меньше трёх точек, самопересечение, ширина не больше нуля), неизвестная динамика или трасса дают понятный `ValueError`. `step` после конца эпизода без `reset` даёт `RuntimeError`. `close()` освобождает ресурсы pygame.

## 8. Тестирование

Разработка по TDD: сначала красные тесты отдельным коммитом. Покрываются геометрия трассы, кинематика, лучи на известной геометрии, контракт среды (`gymnasium.utils.env_checker`), детерминизм по seed, столкновение, завершение круга, загрузка JSON и ошибки, кадр `rgb_array` под dummy-драйвером, разбор аргументов `play.py`.
